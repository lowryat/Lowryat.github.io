Robinhood API Key Maker

Creates the key pair Robinhood asks for. Everything happens in this browser tab; nothing is sent anywhere.

What is happening

Robinhood's crypto API uses a matched pair of keys. You give Robinhood the public key so it can recognize your requests, and you keep the private key so your GitHub job can sign them. This page makes both.

Keep this tab open until both keys are pasted. The private key exists only here. If you close the tab, generate a new pair and redo the Robinhood step. Never paste the private key into Robinhood, email, or a chat.

Then, in Robinhood

1
Open the API pageOn the web: robinhood.com/account/crypto → scroll to API Trading → Add API key. In the app: Account → Crypto → API. Two-factor authentication must be on.
2
Name itSomething like Portfolio monitor (read-only).
3
Paste the public keyUse the Copy button above and paste into the Public key field.
4
Permissions: read onlyTick the read options (account, holdings, orders, market data). Leave every order placement / trading permission unticked. This dashboard never trades.
5
Skip IP allow-list, set no expiry (or one year)GitHub's runners use changing IP addresses, so an allow-list would block the daily job.
6
Approve and copy the API keyRobinhood may ask you to confirm in the app. It then shows an API key string. Copy it.

Finally, in GitHub

7
Open repository secretsgithub.com/lowryat/Lowryat.github.io/settings/secrets/actions
8
New repository secret → ROBINHOOD_API_KEYValue: the API key string Robinhood showed in step 6.
9
New repository secret → ROBINHOOD_PRIVATE_KEYValue: the private key from this page.
10
Run the jobActions → portfolio-daily → Run workflow, then check that the "Verify credentials" step prints [robinhood] OK.

Prefer the Terminal?

Open Terminal on your Mac (Spotlight → “Terminal”), paste this one line, press Return. It prints the same two keys.

curl -sL https://raw.githubusercontent.com/lowryat/Lowryat.github.io/main/scripts/make_robinhood_key.py | python3
